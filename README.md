# Halo images

The optional image pack for Halo, a personal offline app of saints' quotes.

**To add the images to Halo:** download `halo-images.zip` from the
[latest release](https://github.com/giterichub/Halo-images/releases/latest), then in Halo open
Settings → Original images → **Import halo-images.zip** and pick the file. Halo unpacks it itself.

Direct link: https://github.com/giterichub/Halo-images/releases/latest/download/halo-images.zip

The pack holds the original image of each quote (JPEG, up to 1280 px). Nothing else is here;
the app's code is kept elsewhere.
